# Hermes Stock Sentinel v1.0.0 工作流说明

## 工作流主线

1. 打开工作台
2. 搜索股票
3. 把股票加入关注池
4. 查看实时状态
5. Hermes 监控异动和崩坏风险
6. Hermes 发出提醒
7. 用户按提醒保收益和降风险

## Hermes 作用

Hermes 是本版本的中枢，负责：

- 盯关注池
- 识别急跌
- 识别流动性恶化
- 识别崩坏风险
- 输出快讯和优先级

## 页面结构

- 左侧：搜索、关注池、监控模式、工作流
- 中间：股票实时信息、走势、风控评分
- 右侧/下方：快讯、排行、策略规则、Hermes 对话

## 当前版本边界

- 单用户
- 无登录
- 无商业化后台
- 先把 Hermes 提醒能力跑通
