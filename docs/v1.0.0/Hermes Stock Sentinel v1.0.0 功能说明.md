# Hermes Stock Sentinel v1.0.0 功能说明

## 版本目标

这是面向股农群体的单用户股票监控版本。

核心目标：

- 搜索股票
- 关注股票
- 查看实时状态
- 由 Hermes 做风险提醒
- 在异动和崩坏时保护收益

## 已完成功能

- 搜索股票并聚焦
- 本地关注池管理
- 实时信息展示
- Hermes 风控评分
- Hermes 快讯提醒
- 关注股风险排行
- 保收益检查单
- Hermes 策略规则面板
- Hermes 对话控制台
- 本地启动
- Cloudflare 公网分享
- 公网地址查询

## 启动入口

- 本地启动：
  `启动 Hermes Stock Sentinel v1.0.0.command`
- 公网分享：
  `启动 Hermes Stock Sentinel 公网分享.command`
- 查询公网地址：
  `查询当前公网地址.command`

## 当前限制

- 当前还是前端原型
- 使用模拟 Tick
- 还没有接入真实行情 API
- 不包含登录和多用户能力
