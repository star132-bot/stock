# Hermes Stock Sentinel v1.0.0 产品定义

## 版本定位

`v1.0.0` 是单一用户版本，不做登录，不做多用户，不做商业化后台。

目标用户：

- 股农群体
- 需要盯盘的人
- 担心利润回撤和盘中崩坏的人

核心目标：

- 搜索股票
- 搜索后自动关注股票
- 查看实时信息
- 由 Hermes 持续监控风险
- 在股市异动和紧急崩坏时及时提醒用户

## Hermes 的角色

Hermes 是整个 `v1.0.0` 的中枢，不是附属聊天工具。

Hermes 负责：

- 监控关注池
- 判断异动、急跌、放量、流动性恶化
- 识别是否进入崩坏风险
- 输出快讯、排行、保护建议
- 帮助用户保住收益

## 当前实现模块

### 1. 搜索与关注

- 支持按股票代码或名称搜索内置股票
- 支持裸代码输入，例如 `688766`
- 支持本地股票目录匹配后动态生成展示记录
- 搜索命中后自动加入关注池
- 支持最近搜索记录
- 支持加入关注池
- 支持移出关注池
- 支持重置默认关注池

### 2. 实时股票信息

- 最新价
- 涨跌幅 / 涨跌额
- 开高低收
- 成交量 / 成交额
- 买一 / 卖一
- 点差
- 盘中简化走势

### 3. 关注池

- 单用户本地持久化
- 支持按市场范围筛选
- 关注池中显示保护分与涨跌幅

### 4. Hermes 风控镜头

- 趋势确认
- 流动性
- 波动稳定度
- 收益保护

### 5. 关注股排行与详情

- 对关注池股票按风险优先级排序
- 让用户先处理最危险的股票

### 6. Hermes 快讯

- 市场态势播报
- 回撤扩张提醒
- 放量拉升提醒
- 流动性恶化提醒

### 7. 市场总览

- 市场态势
- 上涨家数
- 当前最危险标的
- 当前最强关注股

### 8. 保收益检查单

- 回撤风险
- 流动性
- 波动状态
- 成交确认
- Hermes 建议

### 9. Hermes 策略规则面板

- 急跌守卫
- 保收益优先
- 放量异动筛查
- 崩坏响应

### 10. Hermes 告警中心

- 保存最近一段时间内的 Hermes 风险事件
- 便于回看市场是如何一步步恶化的

### 11. Hermes 对话控制台

支持用自然语言问：

- 当前最危险的股票是谁
- 为什么发提醒
- 哪些股票需要优先关注
- 当前该偏进攻还是防守

## 当前数据状态

`v1.0.0` 仍是前端原型：

- 当前使用内置样本股票
- 使用模拟 Tick 刷新
- 还没有接入真实行情 API

## 下一阶段扩展方向

- 接入真实 Snapshot + WebSocket 数据网关
- 扩展 Hermes 告警规则
- 板块联动和市场级崩坏识别
- 固定域名服务器部署
- 后续如果需要，再作为扩展分支加入登录和账户体系
