# Hermes Stock Sentinel v1.0.0 工作流

## 主工作流

1. 用户打开 Hermes 工作台
2. 用户搜索股票
3. 用户把股票加入关注池
4. 页面持续刷新股票实时状态
5. Hermes 持续监控关注池
6. Hermes 判断是否出现异动、急跌、流动性恶化、崩坏风险
7. Hermes 输出：
   - 快讯
   - 风险提醒
   - 优先级排行
   - 保收益建议
8. 用户根据 Hermes 提醒快速处理风险

## 页面工作流

### 左侧

- 搜索与关注
- 监控模式切换
- Hermes 当前任务
- 关注池
- v1.0.0 工作流说明

### 中间和右侧

- 当前选中股票的实时信息
- Hermes 风险态势
- 风控评分
- 关注股排行与详情
- Hermes 快讯
- 保收益检查单
- Hermes 策略规则
- Hermes 对话控制台

## Hermes 三层职责

### 1. 监控

- 持续盯盘
- 持续盯关注池
- 持续盯市场状态

### 2. 判断

- 判断风险是否升高
- 判断当前是否进入防守区
- 判断是否出现崩坏级预警

### 3. 提醒

- 把风险转换成用户可理解的信息
- 给出先看谁、先处理什么、为什么提醒

## v1.0.0 的闭环

`搜索 -> 关注 -> 实时刷新 -> Hermes 监控 -> Hermes 提醒 -> 用户响应`

只要这条链路稳定，`v1.0.0` 就成立。
